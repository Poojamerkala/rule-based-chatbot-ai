 ## Rule-Based-Chatbot-AI
 
 ## Project Overview
 
This project is a **simple AI Rule-Based Chatbot** developed using **Python**.
The chatbot interacts with users through the command line and responds based on predefined rules using **regular expressions**.
It can handle basic conversation such as greetings, polite responses, and providing the **current date and time**.
This project is created as part of learning **Artificial Intelligence and Python programming**.


## Features

* Responds to greetings like **Hi, Hello, Hey**
* Answers **How are you**
* Tells its name
* Responds to **Nice to meet you**
* Replies to **Thank you**
* Displays the **current date**
* Displays the **current time**
* Allows user to exit the chatbot
* Gives a default response for unknown inputs


## Technologies Used

* **Python**
* **Regular Expressions (`re` module)**
* **Datetime (`datetime` module)**

## How to Run the Project

1. Make sure **Python** is installed on your computer.
2. Download or clone the repository.
3. Run the chatbot program:
python chatbot.py
4. Start chatting with the chatbot in the terminal.

## Example Interaction

AI Chatbot started. Type 'exit' to quit.

You: hello
Chatbot: Hello!

You: what is the time
Chatbot: The current time is 10:30:20

You: today's date
Chatbot: Today's date is 2026-03-08
